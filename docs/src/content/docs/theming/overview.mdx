One of RapiDoc's biggest strengths is its styling model. Because RapiDoc is implemented as a standard Web Component, its internal markup and stylesheet reside inside an **encapsulated Shadow DOM**.

<Aside type="tip" title="Why Shadow DOM Encapsulation Matters">
  In large web applications, global CSS rules (such as CSS resets, utility frameworks, or third-party component libraries) frequently clash
  with embedded documentation widgets. With Shadow DOM: - External CSS cannot accidentally break RapiDoc's internal elements. - Internal
  RapiDoc styles will never bleed out into your parent application.
</Aside>

To style RapiDoc, you have two primary mechanisms:

1. **Attribute-based Configuration**: Simple, declarative HTML attributes for colors, fonts, and layout settings.
2. **CSS Shadow Parts (`::part()`)**: Deep, granular styling using modern CSS pseudo-elements for gradients, borders, and custom UI components.

## 1. Simplified Attribute-Based Theming

RapiDoc v11 provides a streamlined theming interface powered by semantic design tokens aligned with shadcn/ui. You can customize the entire appearance with just 3 primary attributes:

```html
<rapi-doc spec-url="https://api.example.com/openapi.json" theme="amber" color-scheme="dark" radius="sm" scale="default"></rapi-doc>
```

### Core Attribute Reference

| Attribute          | Options                                                                                | Default     | Description                                                                                 |
| :----------------- | :------------------------------------------------------------------------------------- | :---------- | :------------------------------------------------------------------------------------------ |
| `theme`            | `amber`, `blue`, `emerald`, `violet`, `rose`, `graphite`, `slate`, `default`, or any `#hex` color | `"amber"`   | Color palette preset matching shadcn/ui themes, or a custom brand color hex/css value.     |
| `color-scheme`     | `dark`, `light`, `system`                                                              | `"dark"`    | UI color mode. `"system"` automatically matches the user's OS dark/light mode preference.   |
| `radius`           | `none`, `sm`, `md`, `lg`, `full`                                                       | `"sm"`      | Corner radius scale applied across cards, method badges, buttons, inputs, and dialogs.      |
| `scale`            | `sm`, `default`, `lg`                                                                  | `"default"` | Component scaling factor adjusting typography, margins, and control heights proportionally. |
| `nav-item-spacing` | `compact`, `default`, `relaxed`                                                        | `"default"` | Sidebar item vertical density and padding, decoupled from font size scaling.                |

### Custom Brand Colors

You can supply your own brand color directly into the `theme` attribute without configuring multiple color variables:

```html
<!-- Use your exact corporate brand color -->
<rapi-doc spec-url="https://api.example.com/openapi.json" theme="#2563eb" color-scheme="dark" radius="md"></rapi-doc>
```

## 2. Typography & Custom Web Fonts

RapiDoc uses high-quality defaults out of the box:

- **Regular / Sans Font**: `--font-sans` or `--font-regular` (default: `"Open Sans", Avenir, "Segoe UI", Arial, sans-serif`)
- **Monospace Font**: `--font-mono` (default: `Monaco, "Andale Mono", "Roboto Mono", Consolas, monospace`)

Typography is configured directly via standard CSS custom properties or shadcn theme variables on `<rapi-doc>`:

```html
<head>
  <!-- 1. Load Google Fonts in your document head -->
  <link rel="preconnect" href="https://fonts.googleapis.com" />
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
  <link
    href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap"
    rel="stylesheet"
  />

  <style>
    /* 2. Style typography using standard or shadcn CSS variables */
    rapi-doc {
      --font-sans: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;
      --font-mono: 'JetBrains Mono', 'Fira Code', monospace;
    }
  </style>
</head>

<body>
  <rapi-doc
    spec-url="https://petstore.swagger.io/v2/swagger.json"
    scale="default"
  ></rapi-doc>
</body>
```

### Scale Presets

The `scale` attribute controls typography, base sizing, and proportional margins:

- `scale="sm"`: Compact scale (13px base), ideal for embedded panels and dense developer portals.
- `scale="default"`: Balanced standard scale (14px base, standard desktop layout).
- `scale="lg"`: High-readability scale (15px base), optimal for accessibility and presentation modes.

## 3. Dynamic Theme Switching at Runtime

Because `<rapi-doc>` is a standard DOM element, you can dynamically switch themes or color schemes at runtime with vanilla JavaScript:

```javascript
const doc = document.querySelector('rapi-doc');

// Switch preset and mode
function applyTheme(preset, isDark) {
  doc.setAttribute('theme', preset); // 'amber', 'graphite', 'modern', etc.
  doc.setAttribute('color-scheme', isDark ? 'dark' : 'light');
}

// Switch corner radius
function setRadius(size) {
  doc.setAttribute('radius', size); // 'none', 'sm', 'md', 'lg', 'full'
}
```
