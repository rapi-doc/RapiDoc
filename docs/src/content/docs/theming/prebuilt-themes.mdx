title: Pre-built Themes
description: RapiDoc's five built-in themes (Ember, Carbon, Cobalt, Jade, Indigo), each with a dark and a light palette, plus custom brand colors and automatic OS switching.
---

import { Tabs, TabItem, Aside } from '@astrojs/starlight/components';

RapiDoc ships **five themes**. Each one defines an accent and, where the theme tints its surfaces, a background and foreground for both color schemes; every other color (cards, muted text, borders, inputs) is derived from those, so a theme looks consistent in `color-scheme="dark"`, `"light"` and `"system"`.

| Theme | Accent (dark / light) | Dark surface | Character |
| :--- | :--- | :--- | :--- |
| `ember` (default) | `#f76b39` / `#f76b39` | Neutral charcoal `#1f1f23` | Warm, high-energy |
| `carbon` | `#fafafa` / `#18181b` | Near-black `#121214` | Monochrome, terminal-like |
| `cobalt` | `#60a5fa` / `#2563eb` | Navy slate `#0b1220` | Classic developer portal |
| `jade` | `#34d399` / `#047857` | Green-black `#0c1512` | Payments, banking, infrastructure |
| `indigo` | `#818cf8` / `#4f46e5` | Indigo-black `#0f0e1c` | SaaS and platform products |

Light mode uses a white background in every theme; the tinted themes carry their hue into the text, cards and borders.

Try them side by side on the [Themes example](/examples/themes).

## Ember (default)

Orange-red accent over neutral charcoal. This is what you get without a `theme` attribute.

<Tabs>
  <TabItem label="Dark">
```html

```
  </TabItem>
  <TabItem label="Light">
```html
<rapi-doc spec-url="https://petstore.swagger.io/v2/swagger.json" theme="ember" color-scheme="light"></rapi-doc>
```

  </TabItem>

## Custom brand color

Pass a hex code as the `theme`. RapiDoc sets `--primary` and `--ring` to it and picks black or white for `--primary-foreground` by luminance, over the default (Ember) surfaces.

```html
<rapi-doc spec-url="https://petstore.swagger.io/v2/swagger.json" theme="#2563eb" color-scheme="dark" radius="md"></rapi-doc>
```

To change more than the accent, set the CSS variables on the element; see [Theming Overview](/docs/theming/overview/).

```css
rapi-doc {
  --background: #0b1220;
  --foreground: #e2e8f0;
}
```

## Follow the operating system

`color-scheme="system"` switches between the theme's dark and light palette with the OS preference. `color-scheme="auto"` follows the host page's `data-theme` instead.

```html
<rapi-doc spec-url="https://petstore.swagger.io/v2/swagger.json" theme="jade" color-scheme="system"></rapi-doc>
```
