import { Tabs, TabItem, Aside } from '@astrojs/starlight/components';

Looking for a cohesive aesthetic without designing color tokens from scratch? RapiDoc includes **9 built-in presets** inspired by modern design systems, fully compatible with both dark and light color modes.

---

## 1. Amber Minimal (Default Fallback)

Warm amber highlights over deep charcoal surfaces. Delivers high contrast and warm visual polish.

<Tabs>
  <TabItem label="Dark Mode">
```html
<rapi-doc
  spec-url="https://petstore.swagger.io/v2/swagger.json"
  theme="amber"
  color-scheme="dark"
  radius="sm"
  scale="default"
></rapi-doc>
```
  </TabItem>

<TabItem label="Light Mode">
  ```html
  <rapi-doc
    spec-url="https://petstore.swagger.io/v2/swagger.json"
    theme="amber"
    color-scheme="light"
    radius="sm"
    scale="default"
  ></rapi-doc>
  ```
</TabItem>

  <TabItem label="CSS Enhancements">
```css
/* Add subtle amber focus ring and border styling */
rapi-doc::part(section-navbar) {
  border-right: 1px solid var(--border);
}
rapi-doc::part(textbox-nav-filter) {
  border-radius: var(--radius);
}
```
  </TabItem>
</Tabs>

## 8. Custom Corporate Brand Hex Color

Supply your exact brand hex code into `theme`. RapiDoc automatically manages focus rings and accessible foreground text contrast.

```html
<rapi-doc spec-url="https://petstore.swagger.io/v2/swagger.json" theme="#2563eb" color-scheme="dark" radius="md"></rapi-doc>
```

---

## 9. Automatic OS Dark / Light Switching (`system`)

To match the end user's operating system preferences automatically, set `color-scheme="system"`:

```html
<rapi-doc spec-url="https://petstore.swagger.io/v2/swagger.json" theme="emerald" color-scheme="system" radius="md"></rapi-doc>
```
