import { Tabs, TabItem, Aside } from '@astrojs/starlight/components';

Looking for a sleek, cohesive look without designing color tokens from scratch? With RapiDoc v11, selecting a preset requires just `theme`, `color-scheme`, and `radius`.

---

## 1. Midnight Blue (Developer Portal)

Deep dark theme accented with vivid blue highlights and crisp borders.

<Tabs>
  <TabItem label="HTML Attributes">
```html
<rapi-doc
  spec-url="https://petstore.swagger.io/v2/swagger.json"
  theme="blue"
  color-scheme="dark"
  radius="md"
  scale="default"
></rapi-doc>
```
  </TabItem>

  <TabItem label="CSS Enhancements">
```css
/* Add subtle border styling */
rapi-doc::part(section-navbar) {
  border-right: 1px solid rgba(255, 255, 255, 0.08);
}
rapi-doc::part(textbox-nav-filter) {
  border-radius: var(--radius);
}
```
  </TabItem>
</Tabs>
