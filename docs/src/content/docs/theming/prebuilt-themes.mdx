import { Tabs, TabItem, Aside } from '@astrojs/starlight/components';

Looking for a sleek, cohesive look without designing color tokens from scratch? Below are tested, production-ready themes you can drop directly into your `<rapi-doc>` tag.

---

## 1. Midnight Cyan (Modern Developer Portal)

Inspired by cutting-edge developer tools and dark terminal palettes. Features deep slate backgrounds, high-contrast typography, and glowing cyan accents.

<Tabs>
  <TabItem label="HTML Attributes">
```html
<rapi-doc
  spec-url="https://petstore.swagger.io/v2/swagger.json"
  theme="dark"
  bg-color="#06090e"
  text-color="#94a3b8"
  primary-color="#06b6d4"
  header-color="#0b111e"
  nav-bg-color="#080c14"
  nav-text-color="#cbd5e1"
  nav-hover-bg-color="rgba(255, 255, 255, 0.05)"
  nav-hover-text-color="#38bdf8"
  nav-accent-color="#06b6d4"
  regular-font="'Inter', sans-serif"
  mono-font="'JetBrains Mono', monospace"
></rapi-doc>
```
  </TabItem>

  <TabItem label="CSS Enhancements">
```css
/* Add subtle border styling */
rapi-doc::part(section-navbar) {
  border-right: 1px solid rgba(255, 255, 255, 0.08);
}
rapi-doc::part(textbox-nav-filter) {
  background: rgba(15, 23, 42, 0.7);
  border: 1px solid rgba(56, 189, 248, 0.2);
  border-radius: 6px;
  color: #f8fafc;
}
```
  </TabItem>
</Tabs>

A serious, polished dark charcoal theme accented with vivid emerald green, ideal for payments, banking, and security infrastructure APIs.

<Tabs>
  <TabItem label="HTML Attributes">
```html

  spec-url="https://petstore.swagger.io/v2/swagger.json"
  theme="dark"

  nav-bg-color="#090d16"
  nav-text-color="#cbd5e1"

  nav-accent-color="#10b981"

  mono-font="'Fira Code', monospace"
```

  </TabItem>

  </TabItem>
</Tabs>
