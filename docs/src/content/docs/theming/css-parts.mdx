While standard attributes handle core colors and fonts, modern web applications often demand bespoke layouts—such as custom glassmorphism, multi-stop gradient navigation panels, custom borders, and branded buttons.

Because RapiDoc is implemented as a standard W3C Web Component, standard external CSS selectors cannot pierce the Shadow DOM encapsulation boundary. To provide complete design freedom while preserving stability, RapiDoc exposes **CSS Shadow Parts** (`::part()`) and **CSS Custom Properties** (Variables).

---

## 1. How `::part()` Works

In your parent application stylesheet or `<style>` block, select `<rapi-doc>` followed by `::part(part-name)`:

```css
/* Target the sidebar navigation panel inside RapiDoc */
rapi-doc::part(section-navbar) {
  background: linear-gradient(180deg, #090d16 0%, #030712 100%);
  border-right: 1px solid rgba(56, 189, 248, 0.15);
  box-shadow: 4px 0 24px rgba(0, 0, 0, 0.4);
}
```

## 3. CSS Custom Properties (Variables)

In addition to Shadow Parts, RapiDoc exposes a comprehensive set of CSS variables on `:host`. You can override these variables on `<rapi-doc>` or any ancestor container in your stylesheet or inline styles:

```css
rapi-doc {
  --border-radius: 8px;
  --font-mono: 'JetBrains Mono', monospace;
  --primary-color: #10b981;
  --nav-bg-color: #0b1121;
}
```

## 4. Practical Styling Recipes

### Recipe 1: Frosted Glass Sidebar with Neon Accents

```css
/* Add modern backdrop blur and subtle border */
rapi-doc::part(section-navbar) {
  background: rgba(10, 15, 26, 0.85);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border-right: 1px solid rgba(255, 255, 255, 0.08);
}

/* Style the filter input inside the sidebar */
rapi-doc::part(textbox-nav-filter) {
  background: rgba(15, 23, 42, 0.6);
  border: 1px solid rgba(56, 189, 248, 0.2);
  border-radius: 8px;
  color: #f8fafc;
  padding: 8px 12px;
}

rapi-doc::part(textbox-nav-filter):focus {
  border-color: #06b6d4;
  box-shadow: 0 0 0 3px rgba(6, 182, 212, 0.2);
}
```

### Recipe 2: Custom "TRY" and Action Buttons

```css
/* Style primary action buttons with vibrant gradient and glow */
rapi-doc::part(btn-fill) {
  background: linear-gradient(135deg, #06b6d4 0%, #3b82f6 100%);
  color: #ffffff;
  font-weight: 600;
  border: none;
  border-radius: 8px;
  padding: 8px 16px;
  transition: all 0.2s ease;
  box-shadow: 0 4px 12px rgba(6, 182, 212, 0.25);
}

rapi-doc::part(btn-fill):hover {
  transform: translateY(-1px);
  box-shadow: 0 6px 16px rgba(6, 182, 212, 0.4);
}
```

<Aside type="tip" title="Combining Attributes, Variables, and CSS Parts">
The recommended architecture is setting your foundational colors and typography using HTML attributes and CSS variables, and reserving `::part()` for high-impact visual customizations such as gradients, backdrop filters, and custom container borders.
</Aside>
