Exposing every HTTP endpoint as an individual tool floods the agent's context window, leaks internal endpoints, and pollutes tool arguments with transport details.

RapiDoc includes a client-side **Curated MCP Server Generator** that reads your plain OpenAPI spec, applies **smart heuristics** to drop internal and deprecated operations, strip transport headers and classify reference data, and compiles the result into clean MCP servers.

## 1. Zero-Config Smart Heuristics

RapiDoc needs no extra annotations. It derives every tool and resource from standard OpenAPI fields:

1. **Tool Naming**: The tool name is the snake_case form of the `operationId` (`placeOrder` becomes `place_order`). Operations without an `operationId` get a name derived from the HTTP method and path.
2. **Tool Descriptions**: The operation `summary` is used, else its `description`, else `METHOD /path`. HTML and Markdown are stripped and the text is truncated to 300 characters.
3. **Endpoint Exclusion**: Operations marked `x-internal: true` or `x-hidden: true`, operations marked `deprecated: true`, and webhooks are left out.
4. **Automatic Header Pruning**: Headers like `Authorization`, `Cookie`, `X-Api-Key`, `User-Agent` and other transport metadata are stripped from LLM tool arguments. Generated servers send a Bearer token from the `API_KEY` environment variable (or a per-call `apiKey` argument) and read the base URL from `API_BASE_URL`.
5. **Static Resource Classification**: A `GET` with no required parameters on a reference-data path (`/reference`, `/currencies`, `/countries`, `/tiers`, `/categories`, `/status`, `/schema`) becomes an **MCP Resource** (`reference://<name>`) instead of a tool, avoiding function-calling overhead.
6. **Confirmation Flags**: `POST`, `PUT`, `PATCH` and `DELETE` operations are flagged as consequential, so hosts can ask the user before running them.
7. **Token Budget Calculation**: Real-time diagnostic calculation estimates prompt token overhead and warns when total tools exceed recommended limits (>30 tools or >5,000 tokens).

## 2. Annotated OpenAPI Example

Here is a plain OpenAPI 3.x snippet and how each operation is treated:

```yaml
openapi: 3.0.3
info:
  title: Commerce Fulfillment API
  version: 2.4.0

paths:
  # 1. Tool "place_order", flagged as needing confirmation (POST)
  /orders:
    post:
      summary: Place a new order
      operationId: placeOrder
      parameters:
        - name: Authorization # Stripped: supplied by the server from API_KEY
          in: header
          schema: { type: string }
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [customerId, items]
              properties:
                customerId: { type: string }
                items: { type: array, items: { type: string } }
                shippingMethod: { type: string, enum: [standard, express, overnight] }

  # 2. Read-only tool "get_order"
  /orders/{orderId}:
    get:
      summary: Get an order
      operationId: getOrder
      parameters:
        - name: orderId
          in: path
          required: true
          schema: { type: string }

  # 3. MCP Resource "reference://currencies" (GET, no required params, reference-data path)
  /currencies:
    get:
      summary: List supported currencies
      operationId: getCurrencies

  # 4. Excluded: internal endpoint
  /admin/database/vacuum:
    post:
      summary: Trigger internal database maintenance
      x-internal: true

  # 5. Excluded: deprecated endpoint
  /orders/legacy:
    get:
      summary: Legacy order list
      deprecated: true
```

## 4. Enterprise Code Generation Standards

Generic converters produce brittle, insecure code that fails when deployed to production agent hosts or multi-tenant proxies. RapiDoc enforces strict engineering invariants across all 6 target runtimes:

### 1. Dynamic Path Traversal & Injection Immunity
Generic converters use naive string interpolation (e.g. `fmt.Sprintf("/items/%s", id)` in Go or `$"{BaseUrl}/items/{id}"` in C#). When an agent supplies an identifier containing path traversal tokens (e.g., `../../admin`), this exposes backend servers to path traversal and route hijacking.

RapiDoc systematically applies language-native RFC 3986 URL percent-encoding across all targets:
- **Go**: `url.PathEscape(param)` via `net/url`
- **C#**: `Uri.EscapeDataString(param)` via `System`
- **Rust**: `urlencoding::encode(&param)` via `urlencoding`
- **Python**: `urllib.parse.quote(str(param), safe="")` via standard library
- **TypeScript**: `encodeURIComponent(String(param))`
- **Java**: `URLEncoder.encode(String.valueOf(param), StandardCharsets.UTF_8)`

### 2. Dual-Mode Multi-Tenancy (Stdio vs. Gateway)
When running locally in desktop agents (like Claude Desktop or Cursor), servers authenticate using host environment variables (`process.env.API_KEY`, `os.Getenv("API_KEY")`).

However, when deployed in multi-tenant environments (such as team agent gateways or SaaS orchestrators), multiple users share the same server process. RapiDoc generates dual-mode authentication resolution:
- Dynamically inspects tool arguments for per-turn execution keys (`args.apiKey` or `args.api_key`).
- If present, uses the tenant-specific key for the outbound request.
- If omitted, gracefully falls back to the host environment variable.
- Automatically strips credentials from public log streams.

### 3. RFC 6570 Resource Query Parameter Forwarding & Secret Scrubbing
When an AI agent requests an MCP Resource containing query parameters (e.g., `reference://orders?status=active&apiKey=secret`), naive generators fail to parse query strings or drop them entirely.

RapiDoc's resource handlers:
1. Safely split the URI at the query delimiter (`?`).
2. Parse query parameters dynamically according to RFC 6570.
3. Extract and scrub authentication tokens (`apiKey`, `api_key`).
4. Re-serialize valid parameters and forward them to backend API endpoints.

### 4. Zero-Dependency Lightweight Runtimes
Generated servers avoid heavy third-party networking bloat:
- **Python**: Generated with Jeremiah Lowin's `fastmcp` using Python's built-in `urllib.request`. Zero external HTTP client libraries required.
- **Go**: Uses standard library `net/http` and `mark3labs/mcp-go`, compiling to a single standalone static binary with **under 15ms cold start**.
- **Rust**: Uses `tokio` and `mcp-sdk` for an ultra-lean memory footprint of **under 10 MB RAM**.
- **C#**: Uses .NET 8 / 9 native `HttpClient` with standard method reflection attributes.
- **Java**: Uses Spring AI MCP starter with clean `@Bean` definitions and Spring Boot `RestClient`.

### 5. First-Class Collection Type Schemas
OpenAPI arrays are translated into first-class collection schemas rather than generic object blobs (`mcp.WithList()` in Go, `IEnumerable<string>` in C#, `Vec<String>` in Rust), ensuring host models understand schema structure without guessing.

## 5. Integrating with `<rapi-doc>`

### HTML Attributes

Configure the **`mcp`** attribute on your `<rapi-doc>` element:

```html
<!-- Single target (direct export button) -->
<rapi-doc
  spec-url="/specs/my-api.yaml"
  mcp="typescript"
  mcp-server-name="my-api-mcp"
> </rapi-doc>

<!-- Multiple targets (interactive export dropdown) -->
<rapi-doc
  spec-url="/specs/my-api.yaml"
  mcp="typescript, python, go, csharp, rust, java"
  mcp-server-name="my-api-mcp"
> </rapi-doc>
```

- **`mcp`** (`string | string[]`, default: `"none"`): Enables and configures MCP server export for AI agents.
  - **Single language:** e.g. `mcp="python"` renders a direct `[Export MCP Server (Python)]` button in the API overview.
  - **Multiple languages:** Comma-separated string in HTML (e.g. `mcp="typescript, python, go"`) or string array in JavaScript (e.g. `doc.mcp = ['typescript', 'python']`). Renders an `[Export MCP Server ▾]` dropdown menu.
  - **Supported targets:** `typescript`, `python`, `go`, `csharp` (or `c#`), `rust`, `java`.
  - **Kill-switch:** Setting or including `"none"` or `"false"` anywhere in the list (e.g. `mcp="none, python, go"` or `doc.mcp = ['none', 'python']`) completely disables export.
- **`mcp-server-name`** (`string`, optional): Custom identifier for the generated MCP server. Defaults to the specification title.

### Programmatic JavaScript API

You can generate code, trigger downloads, or inspect token costs programmatically:

```javascript
const doc = document.querySelector('rapi-doc');

// 1. Generate in-memory code, host configuration, and token diagnostics
const result = doc.generateMcpServer('python', { serverName: 'my_store_mcp' });
console.log(result.serverCode); // Complete Python FastMCP source
console.log(result.budget);     // { totalTools: 5, estimatedTokens: 850, ... }
console.log(result.hostConfig); // Claude Desktop / Cursor config JSON

// 2. Trigger browser download of server file (e.g. server.py, main.go, server.ts)
doc.downloadMcpServer('go');

// 3. Inspect token budget overhead before exporting
const budget = doc.getMcpBudget();
console.log(`Overhead: ~${budget.estimatedTokens} tokens/turn across ${budget.totalTools} tools.`);
```
