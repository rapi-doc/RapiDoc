JavaScript API

DOM Methods#

Methods accessible directly on the <rapi-doc> DOM element instance (e.g. document.getElementById('doc').loadSpec(...)) for seamless programmatic interaction.

Programmatic Control Example
// Programmatically control RapiDoc from your web app
const rapidoc = document.getElementById('the-doc');

// Switch API server on runtime event
rapidoc.setApiServer('https://staging-api.example.com/v1');

// Programmatically scroll to and open a specific endpoint
rapidoc.scrollToPath('get-/users/{id}');

// Set credentials dynamically
rapidoc.setApiKey('api_key_header', 'sk_live_9482910481029');
Method NameDescription & Usage
loadSpec(spec)#Example Code
Programmatically loads a new OpenAPI specification. Accepts either a string URL or a valid in-memory JSON/JavaScript spec object.
scrollToPath(path)#Example Code
Programmatically scrolls the viewport to focus on a specific endpoint section. The path argument must be formatted as {method}-{path} (e.g., get-/user/login).
setHttpUserNameAndPassword(securitySchemeId, username, password)#
Programmatically supplies username and password credentials for an HTTP Basic security scheme declared in the spec.
setApiKey(securitySchemeId, token)#
Programmatically provides the token or key for a declared API Key or Bearer Token security scheme.
setApiServer(apiServerUrl)#
Programmatically switches the active target API server URL.

Runtime Hooks

Lifecycle & Console Events#

Standard CustomEvents dispatched by <rapi-doc> that allow you to intercept request pipelines, inject authorization headers, capture metrics, and respond to UI state changes.

Event Interceptor Example
// Intercept requests and add authentication or telemetry
const rapidocEl = document.getElementById('the-doc');

// Fires before the HTTP request is dispatched
rapidocEl.addEventListener('before-try', (e) => {
  if (e.detail.request.method === 'POST') {
    e.detail.request.headers.append('X-Tenant-ID', 'corp-acme-123');
  }
});

// Fires when API server selection changes
rapidocEl.addEventListener('api-server-change', (e) => {
  console.log('Selected target server:', e.detail.selectedServer);
});
Event NameDescription & Payload
before-render#
Dispatched before rendering starts. Provides the parsed OpenAPI specification object via e.detail.spec, allowing programmatic modifications before the UI tree is built.
spec-loaded#
Dispatched after the OpenAPI specification has been fully fetched, parsed, resolved, and rendered into the DOM. Provides the resolved spec object in e.detail.
before-try#
Dispatched when a user clicks "TRY" before the network request is initiated. Provides a mutable Request-like object via e.detail.request to append headers, rewrite parameters, or modify payloads, along with an AbortController via e.detail.controller to abort requests conditionally.

Example: Append custom authorization headers before sending: 
 rapidocEl.addEventListener('before-try', (e) => {
  if (e.detail.request.method === 'POST') {
    e.detail.request.headers.append('X-Tenant-ID', 'corp-acme-123');
  }
});
Example: Append query parameters to all GET requests: 
 rapidocEl.addEventListener('before-try', (e) => {
  if (e.detail.request.method === 'GET') {
    const url = new URL(e.detail.request.url);
    url.searchParams.append('client_version', '2.4.0');
    e.detail.request.url = url.toString();
  }
});
Example: Abort specific requests conditionally: 
 rapidocEl.addEventListener('before-try', (e) => {
  if (e.detail.request.method === 'DELETE') {
    alert('DELETE operations are disabled in this sandbox environment.');
    e.detail.controller.abort();
  }
});
after-try#
Dispatched after a try request completes. Provides e.detail.request and e.detail.response. In the event of a network or protocol error, provides request and error objects.
request-aborted#
Dispatched when an in-flight API try request is aborted by the user or programmatically via AbortController.
api-server-change#
Dispatched when the active target API server is modified in the dropdown.
Component Slots

HTML Template Slots#

Standard Web Component slots that enable embedding your custom HTML, logos, corporate banners, and notices directly at specific locations within the RapiDoc UI canvas.

Slot Injection Example
<rapi-doc spec-url="https://petstore.swagger.io/v2/swagger.json">
  <!-- Default slot: Renders custom banner directly below top navigation -->
  <div class="custom-hero">
    <h1>Enterprise API Portal</h1>
  </div>

  <!-- Named slot: Custom logo inside the sidebar -->
  <img slot="nav-logo" src="/brand/logo.svg" alt="Company Logo" width="36" height="36" />

  <!-- Named slot: Custom notice above authentication panel -->
  <div slot="auth" class="auth-notice">
    <p>Please obtain API tokens from the Internal Developer Console.</p>
  </div>
</rapi-doc>
