Uncompromising Engineering

Why Teams Choose RapiDoc Over Alternatives

Designed from the ground up for developer productivity, enterprise privacy, and product design flexibility.

Framework Agnostic

Native W3C Web Component Standard

Free of proprietary wrapper lock-in, complicated build steps, or framework runtime baggage. Drop a single <rapi-doc> custom element into React, Vue, Angular, Next.js, Nuxt, Astro, or plain vanilla HTML. Change attributes with JavaScript and it responds instantly.

No React Hydration OverheadZero Build StepUniversal Interoperability
Real DX

Built-in Console with Negative Testing

Execute API calls directly in the docs. Unlike rigid renderers that block invalid inputs, RapiDoc lets you test negative edge cases, corrupt payloads, and custom headers.

Microservices & Edge

Embedded in Micro-Servers & Containers

With its tiny bundle size and zero server-side rendering dependencies, RapiDoc is ideal for embedding into lightweight Docker containers, Go / Rust / Java backends, and IoT edge devices.

Ergonomics

Tree & Tabular Schema Folding

Choose between Tree and Table representation for deep schemas. All models and examples are auto-expanded by default, completely eliminating tedious 20-click accordions.

Enterprise Ready

100% Self-Hosted & Air-Gapped Security

Trusted by Fortune 500 corporations, defense, and fintech organizations. RapiDoc executes entirely client-side in the browser. No telemetry phoning home, no cloud vendor lock-in, and zero risk of proprietary internal API schemas leaking to third parties.

Get Up & Running

Zero Config, Instant Integration

Choose your stack and drop RapiDoc into your application in under 60 seconds.

index.html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <script type="module" src="https://unpkg.com/rapidoc/dist/rapidoc-min.js"></script>
</head>
<body>
  <rapi-doc
    spec-url="https://petstore.swagger.io/v2/swagger.json"
    render-style="read"
    theme="dark"
    show-header="false"
  > </rapi-doc>
</body>
</html>
ApiDocs.tsx
import React from 'react';
import 'rapidoc';

export function ApiReference() {
  return (
    <rapi-doc
      spec-url="https://petstore.swagger.io/v2/swagger.json"
      render-style="view"
      theme="dark"
      style={{ height: '100vh', width: '100%' }}
    />
  );
}
ApiDocs.vue
<template>
  <rapi-doc
    spec-url="https://petstore.swagger.io/v2/swagger.json"
    render-style="focused"
    theme="dark"
    style="height: 100vh; width: 100%"
  />
</template>

<script setup>
import 'rapidoc';
</script>
Dockerfile
FROM nginx:alpine
# Copy rapidoc bundle and your OpenAPI spec into a zero-dependency container
COPY dist/rapidoc-min.js /usr/share/nginx/html/
COPY openapi.yaml /usr/share/nginx/html/
COPY index.html /usr/share/nginx/html/
EXPOSE 80
# Blazing fast, self-contained, <25MB total image size
