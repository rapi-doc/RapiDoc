RapiDoc Mini (Embedded Endpoint Cards)

RapiDoc Mini (Embedded Endpoint Cards)

Section titled “RapiDoc Mini (Embedded Endpoint Cards)”

While <rapi-doc> provides a complete full-page documentation portal with sidebars and navigation, <rapi-doc-mini> is a dedicated lightweight web component designed to render a single isolated endpoint.

It is ideal for embedding interactive “TRY” cards directly inside tutorials, changelogs, markdown blog posts, or internal wiki pages.

2. Key Attributes for rapi-doc-mini

Section titled “2. Key Attributes for rapi-doc-mini”
Attribute Type Default Description
spec-url string "" URL to the OpenAPI specification.
path string "" The path pattern to render (e.g. /users/{id}).
method string "" HTTP method to display (get, post, put, delete, patch).
theme string "light" Visual theme preset ("light" or "dark").
allow-try boolean true Enables interactive execution and live server response preview.
schema-expand-level number 1 Default expansion depth for request and response schema bodies.

3. When to Use rapi-doc-mini vs. Full rapi-doc

Section titled “3. When to Use rapi-doc-mini vs. Full rapi-doc”
Use Case Recommended Component
Full API developer portal / comprehensive reference <rapi-doc render-style="view">
Embedding an interactive API call inside a blog post or tutorial <rapi-doc-mini>
Highlighting a new endpoint in a product release announcement <rapi-doc-mini>
Micro-frontend with dedicated endpoint widgets <rapi-doc-mini>
