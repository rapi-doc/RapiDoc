Section titled “Quickstart & Framework Integration”

4. Essential Attributes Reference

Section titled “4. Essential Attributes Reference”

Here are the most frequently used attributes when initializing RapiDoc:

Attribute Type Default Description
spec-url string "" URL of the OpenAPI / Swagger JSON or YAML specification.
theme string "light" Primary visual mode: 'light' or 'dark'.
render-style string "view" Layout mode: 'read', 'view', or 'focused'.
show-header boolean true Displays the top navigation bar with search, server selection, and auth controls.
allow-try boolean true Allows developers to execute interactive API requests directly from the UI.
allow-authentication boolean true Shows security and API key authentication panels.
primary-color string "#ff791a" Accent color used for buttons, method badges, and active states.
