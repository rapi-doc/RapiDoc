**RapiDoc** turns an OpenAPI spec into interactive API documentation. At its core is `<rapi-doc>`, a single HTML element with no runtime dependencies: add one script tag and it works in any page or framework. Its Shadow DOM keeps your site's styles and RapiDoc's styles apart.

<CardGrid>

## The rest of the family

`<rapi-doc>` is one of several products: RapiDoc Mini, RapiFlow, RapiPdf, RapiMock and RapiDoc Portal, with the RapiDoc CLI, MCP and pre-rendering as tools. The [documentation home](/docs/) lists them all.

Every attribute, method, event and slot of `<rapi-doc>` is listed in the [API reference](/docs/rapidoc/reference/), and the [Examples](/examples) show it running.
