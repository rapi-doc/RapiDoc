## Methods

Called on the element, for example `document.querySelector('rapi-doc')`.

```js
const doc = document.querySelector('rapi-doc');

await doc.loadSpec('https://rapidocui.com/specs/petstore.yaml');
doc.setApiServer('https://petstore3.swagger.io/api/v3');
doc.setApiKey('api_key', 'demo-key');
doc.scrollToPath('get-/pet/{petId}');
```

## Events

CustomEvents dispatched by `<rapi-doc>`. Listen with `addEventListener`; the payload is in `event.detail`.

```js
const doc = document.querySelector('rapi-doc');

// Before a Try request is sent: add a header
doc.addEventListener('before-try', (e) => {
  e.detail.request.headers.append('X-Tenant-ID', 'acme');
});

// The reader picked another server
doc.addEventListener('api-server-change', (e) => {
  console.log('Server:', e.detail.selectedServer);
});
```

## Slots

Put your own markup inside `<rapi-doc>` with a `slot` attribute, and it shows at that place in the element.

```html
<rapi-doc spec-url="https://rapidocui.com/specs/petstore.yaml">
  <img slot="nav-logo" src="/logo.svg" alt="Acme" height="32" />
  <p slot="auth">Get a key from the developer console.</p>
</rapi-doc>
```
