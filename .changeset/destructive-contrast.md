`--destructive` (errors, required markers, DEPRECATED labels) is `#f05050` on dark (it was `#ef4444`; `#f25a5a` with the cobalt theme and `#f98080` with amber, whose surfaces are lighter, so every dark theme keeps 4.5:1) and `#c81e1e` on light (it was `#dc2626`), which keeps 4.5:1 on the light themes' tinted cards. The Deprecated badge on security schemes uses `--destructive` too (it used `--method-delete`), like every other deprecation marker. The named badge colour `--red` (`x-badges` `color: red`) is `#f98080` on dark and `#c81e1e` on light.
