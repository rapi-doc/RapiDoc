New package `@rapidoc/starlight`: a Starlight plugin that adds an API reference page per OpenAPI document, `starlightRapidoc({ path: "/api", spec: "./openapi.yaml" })`. The page is drawn by `<rapi-doc>` in Starlight's layout and themes, and the API's tags and operations are added to Starlight's sidebar.
