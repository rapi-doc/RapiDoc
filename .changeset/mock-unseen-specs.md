`rapidoc mock --stateful` maps more of a spec it has not seen before, after measuring on Jira and DigitalOcean. A collection's list is found by what its item path returns, whatever the property is called (`{ load_balancers: [...], links, meta }`, a page object with `values`). A POST with an object on a resource's collection is taken as a create, marked for review. Where a path takes a number for a key the schema types as text, new keys are numbers in text, so the next request passes validation. A field or resource whose seed data cannot be generated no longer leaves the whole API without state: the resource starts empty and the server says which.
