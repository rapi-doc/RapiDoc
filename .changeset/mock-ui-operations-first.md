The Mock UI puts Operations first. Its table writes each path once beside its methods in colored text, and an operation's page has tabs for the path's other methods and a response table with each status's model, where its body comes from and how to get it. The control API's operation detail says, for each response, where the body comes from (`body`, `examples`) and which response is returned by default (`returned`). Its icons are Phosphor's, as on the portal, and the Dashboard's Lint card shows the share passed as a ring beside one table of categories. Its controls follow `<rapi-doc>`: caps buttons, tabs and section headings, an amber current button in a group, switches for checkboxes.
