On API reference pages, the tabs above the sidebar (`header.tabs: sidebar` or `sidebar-select`) sit inside the sidebar with the same spacing as in the guides' sidebar, instead of against its left edge, and the `sidebar-select` list opens over the endpoint filter instead of under it.
