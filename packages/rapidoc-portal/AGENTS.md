# AGENTS.md — `packages/rapidoc-portal` (PocketBase Developer Portal)

## 1. Package Scope & Identity
`packages/rapidoc-portal` is an early-stage sub-package designed to provide a PocketBase-backed developer portal for hosting, securing, and exploring OpenAPI specifications using RapiDoc.

- **Package Name**: `rapidoc-portal`
- **Module Type**: ESM (`"type": "module"`)
- **Status**: Early development / roadmap integration
